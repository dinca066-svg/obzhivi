# Требования к каталогу производителя

Один товар / комплектация — отдельный SKU. Обязательны: название, производитель, SKU, категория, наружные ширина × глубина × высота в мм, фото товара, ссылка на конкретную комплектацию и статичная GLB 2.0 со встроенными текстурами.

Размер 160×200 у кровати означает матрас, а не наружные габариты. Для расстановки нужны размеры вместе с изголовьем, ножками и выступами. Прикреплять технический чертёж производителя предпочтительнее ручного ввода по маркетплейсу.

GLB: метры, Y вверх; X — ширина, Z — глубина. После нормализации точка установки — центр основания на полу. Один товар, одна сцена, без анимации / скелета / morph targets / внешних файлов. Текущий предел загрузки 50 МБ. Для браузера желательно уменьшать число полигонов и текстуры, проверяя силуэт и материалы.

Нормализация: поворот quaternion → единый uniformScale → центрирование X/Z и основание Y=0. Растяжение отдельно по осям запрещено. Контроль согласованности: максимум 5 мм или 1% по каждой оси. Ошибка пропорций требует исправления модели; Meshy не доказывает реальные габариты.

Фото хранится отдельно от preview модели. В карточке покупателя показывается фото. `productUrl` допускает только HTTP(S), без встроенных логина/пароля. У вариантов отделки отдельный артикул; в прототипе ещё нет переключения материалов по KHR_materials_variants.

Тестовые модели:

- Shane / Melatika: заявлено 1720×2120×1000 мм, модель около 1728×2101,5×1004,1. Ссылка на товар 5971077429 Яндекс Маркета.
- GRV: заявлено 450×400×470 мм, модель около 455×415×470. Ссылка на товар 103724742948. Глубина mesh больше карточки; контур учитывает больший размер.

Для расширения каталога нужны также цена/валюта, регион доставки, наличие, срок обновления, варианты отделки и права на использование фото/моделей. Эти поля и серверная синхронизация каталога — следующий этап.
