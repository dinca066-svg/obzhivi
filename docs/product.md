# Логика продукта и следующие этапы

## Текущий тест

Проверить, может ли новый человек без объяснений загрузить план, выбрать спальню, получить масштаб, задать проёмы, поставить реальную мебель и получить дизайн с узнаваемыми товарами. Пример квартиры помогает пройти путь без собственного плана.

Тестируем четыре вещи: понятность разметки; удобство размещения и поворота мебели; качество опорного ракурса; сохранение архитектуры и идентичности товара в Seedream. Отзывы сохраняются на сервер, не только в браузере.

## Следующая очередь

1. Добавить шкаф как товар: реальные габариты, зона открывания дверей/ящиков, доступ к хранению. Рекомендации сначала фильтруют физическую совместимость, затем стиль, бюджет и наличие.
2. Сохранение проектов на сервер и возвращение с другого устройства; отдельные сущности project / room / sceneRevision / catalogProduct / productVariant / placement / renderJob.
3. Автоматическая черновая разметка плана: контуры, площади, проёмы, confidence; экран обязательной ручной коррекции. Непрямоугольные контуры и несколько комнат.
4. Нормализованный каталог поставщиков и кабинет загрузки. Версии моделей и размеров; хранение изображения / mesh / seller link отдельно.
5. Спонсорское ранжирование только среди подходящих предметов, с маркировкой продвижения. Оплата не отменяет проверку размеров и проходов.
6. Контроль генерации: сравнение проёмов и силуэтов, серии ракурсов в одном стиле, постоянное хранение результата, наблюдаемость ошибок и расходов, webhook провайдера.

Решение владельца для этого теста: сайт публичный без регистрации; лимит количества платных генераций пока не вводим. Защита от случайного дублирования включена. Авторизация полноценного коммерческого сервиса и политика расходов проектируются отдельно.
