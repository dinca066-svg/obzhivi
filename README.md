# Обживи — кабинет каталога мебели

Прототип: загрузка статичного GLB 2.0, 3D-просмотр, внешние габариты в миллиметрах, проверка масштаба, единая коррекция масштаба, поворот по осям, сохранение карточек в IndexedDB и экспорт ZIP с нормализованным GLB и JSON.

Поле `productUrl` хранит ссылку на конкретную комплектацию и входит в экспорт JSON. В карточках отображается кнопка «Посмотреть у продавца» с доменом магазина. Допускаются абсолютные HTTP(S)-ссылки без встроенных логина/пароля; переход открывается в отдельной вкладке. Старые карточки без ссылки продолжают работать. Проверка формата URL не подтверждает наличие товара или актуальность страницы продавца.

## Запуск

Node.js 22+; `npm ci`, `npm test`, `npm run build`, `npm run dev`. Локальный адрес: http://127.0.0.1:8781.

## Контракт модели

- Один товар и одна комплектация в одном самодостаточном GLB; текстуры внутри файла, максимум 50 МБ.
- glTF: метры, Y вверх; ширина X, глубина Z. Точка установки после нормализации — центр основания на полу.
- Указываются наружные размеры вместе с изголовьем, подлокотниками и прочими выступами, а не размер матраса.
- Проверяемая геометрия статична: без анимации, скиннинга и морфов. При несовпадении пропорций требуется исправить модель; растяжение по разным осям запрещено.
- Допуск прототипа: максимум из 5 мм и 1% отдельно для каждого габарита. Это проверка согласованности модели с карточкой, а не подтверждение фактических размеров изделия.
- Варианты отделки оформляются отдельными артикулами комплектации; автоматическое переключение KHR_materials_variants не реализовано.
- Экспорт model.glb содержит применённые трансформации. Сервис комнаты должен загружать его с внешним scale=[1,1,1]. В product.json размеры хранятся в миллиметрах.

## Хранение и границы прототипа

Страница `/planner.html` — примерка кровати в выбранной правой спальне. Использует товары из того же IndexedDB, поддерживает перетаскивание, поворот на 90°, стрелки/клавиатуру, расстояния до стен, привязку, сохранение положения в localStorage. Расстановка не сохраняется при пересечении стен или зоны открывания/подхода к двери. Проходы менее 600 мм подсвечиваются как ориентир; сторона изголовья исключена. Контур для проверки берёт максимум габаритов карточки и измеренной модели по каждой оси.

Комната 3050×5505 мм предварительно оценена по площади 16,79 м² и пропорциям выбранного контура 255×461 пикселей. Дверь и окна размечены приблизительно. Ввод размеров доступен, но статус комнаты остаётся `verified:false`: отдельного процесса подтверждения обмеров пока нет. Учитывается только эта прямоугольная комната и одна кровать; нет проверки радиаторов/высот окон и подбора шкафов. Сохранённые координаты — центр основания от верхнего левого внутреннего угла в миллиметрах, поворот по часовой стрелке на виде сверху. Для будущего Three.js это x/1000,z/1000 и rotation.y=-rotation*PI/180 при +Z вниз по плану.

Карточки и исходные файлы хранятся только в браузере на данном домене. Очистка данных сайта удаляет каталог; для резервной копии доступен экспорт каждой карточки. Общий серверный каталог, роли производителей, публикация товаров, расстановка в комнате, цены и оплаченный приоритет ещё не подключены. Учебные модели создаёт scripts/fixtures.mjs; они не являются изделиями производителя.

Следующий этап: API карточек, объектное хранилище исходных/нормализованных GLB, очередь серверной валидации и статусы draft/validated/published. Клиентскую проверку нельзя использовать как единственный контроль поступающих от поставщиков файлов.


## Поворот, дверь и фото товара

Кнопка поворота закреплена поверх центра кровати на плане и остаётся горизонтальной. Сама кровать перетаскивается за область вне кнопки. Клик на дверной проём открывает настройки: стена (left/right/top/bottom), петли (start/end вдоль стены), открывание (inward/outward), ширина и отступ. Для вертикальных стен отступ от верхнего угла, для горизонтальных — от левого. При смене на короткую стену отступ ограничивается её длиной. Старые сохранения получают left/start/inward.

Пересечения проверяются по сектору 90° открывающейся внутрь створки и отдельному прямоугольному подходу глубиной 600 мм внутри комнаты. При открывании наружу сектор находится снаружи, подход внутри остаётся. Внешний коридор не моделируется. Окна по-прежнему предварительные; их конфликт с переносом двери не проверяется.

Фото хранится отдельно от GLB и thumbnail: `photoDataUrl` (JPG/PNG/WebP до 8 МБ), `photoRemoved`. При выборе мебели 3D-скриншот никогда не подставляется вместо фотографии. Для ранее добавленной Shane по точному URL Маркета используется `public/photos/shane-seller.jpg` — неизменённое изображение из карточки продавца; источник: https://market.yandex.ru/card/krovat-shane-160kh200-dvuspalnaya-s-podyemnym-mekhanizmom-na-nozhkakh-obivka-velyur-belyy-velutto-soft-100-kant-chernyy/5971077429 . URL изображения: https://avatars.mds.yandex.net/get-mpic/19828547/2a0000019f6529c4188cc6b645d7c1d78b04/900x1200 . Пользовательское фото заменяет его; удаление не возвращает изображение по умолчанию. Фото входит в ZIP отдельным файлом и указано в `product.photo` экспортируемого JSON.
